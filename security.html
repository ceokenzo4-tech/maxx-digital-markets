Security Reminder

Never store real customer passwords, private keys or authentication secrets directly inside HTML, JavaScript or browser localStorage.

Production Requirements

A real exchange account system should use HTTPS, server-side authentication, password hashing, secure sessions, database access controls, rate limiting, audit logging and applicable verification and compliance systems.
